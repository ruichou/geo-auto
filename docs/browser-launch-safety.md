# 浏览器启动安全与审计

系统把浏览器启动分为两类：

- `user_explicit`：用户明确点击“注册/登录”“打开工作台”，或显式要求可见发布；允许显示窗口。
- `automation`：定时 AI 探测和到期发布检查；只允许无头浏览器。任何自动化请求可见窗口都会在启动前被硬性拒绝。

每次实际启动都会写入本地 `browser_launch_events` 台账，保存平台、动作、触发类型、是否可见、开始/结束时间和有限错误摘要，不保存 Cookie、账号身份或浏览器资料路径。控制台、策略快照和日报会显示是否出现过“自动化可见启动”。

当发布为 `queue` 或 `publishing.paused=true` 时，到期任务检查会在查询和领取任务前直接返回，不启动浏览器，也不修改任务尝试次数。
