# AI 采样溯源回执

每个新采样都保存统一、可审计且不含凭据的回执：采集方式、提取器版本、适配器配置指纹、平台、surface、区域、语言和模型身份状态。

- 浏览器端无法可靠读取模型名称时，明确记录 `not_exposed`，不猜测。
- 适配器指纹只对允许字段做规范化哈希；密钥、令牌、Cookie、账号身份和浏览器资料路径不进入回执。
- 历史样本缺少这些字段时标为 `legacy_without_receipt`，不会倒填未知信息。
- 策略快照带独立 schema 版本，便于后续比较不同版本的测量工件。

这项能力提高“结果来自哪种采集路径、哪一版提取器和哪套适配器”的可复核性，但不把一次采样包装成稳定排名，也不把未暴露的模型身份视为已知。
