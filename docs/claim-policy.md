# 品牌主张风险策略

系统不以“对 GEO 有利”作为真实性依据。同一套 `claim_policy` 同时用于第一方品牌事实和待发布内容，防止事实审计与内容质量闸门维护两套不一致的禁用词。

默认阻止的高风险类型包括：

- 无依据的成交、中标、获客、收录或推荐保证；
- “行业第一”“全网最好”“唯一推荐”等绝对化排名；
- “100% 真实”“永不过期”等无法持续核查的线索质量承诺；
- “DeepSeek 一定推荐”“保证被 AI 推荐”等对第三方模型输出的不当承诺。

规则同时使用精确标记和有限正则模式。扫描前会移除空白、连字符、下划线和常见分隔点，因此“保 证-成交”或“行-业 第 一”不能绕过闸门。`config/site.json` 的 `claim_policy.prohibited_markers` 只能追加项目特有表述，不会覆盖或关闭内置基线。

为了不阻止必要的风险说明，明确否定表述（如“不保证成交”“不是行业第一”）不作为承诺；带有“吗、是否、是真的吗、会不会”等明确疑问结构的核验问题（如“AI 推荐就代表项目一定真实吗？”）也不作为结论。仅在句尾追加问号、“你觉得如何”或“靠谱吗”的肯定承诺不享受豁免；“靠谱”不单独作为高风险承诺的问句豁免词。否定与问句豁免都有回归测试。

执行结果：

- 品牌事实命中时，证据状态为 `prohibited_claim_language`，事实不进入 LLM 上下文、实体资产或内容闸门；
- 内容命中时，`no_exaggerated_claims=false`，且该项是发布阻断项；
- 回执保留命中类型和文本，用于控制台、报告与独立复核。

边界：这是高风险语言闸门，不是通用真假判定器。没有命中禁用模式的数据、案例、主体和电话声明仍必须通过各自的证据回执，不能因为语言策略通过就视为真实。
